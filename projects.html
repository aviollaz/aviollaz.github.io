SmartCartbackend · data

Splits your grocery cart across Coto, Día, Carrefour and Vea to spend as little as possible. It scrapes the chains every night, matches products with vector search and solves the split with a constraint solver. While scraping, I found a card skimmer injected into three of those stores.

Reparte tu carrito de supermercado entre Coto, Día, Carrefour y Vea para gastar lo menos posible. Scrapea las cadenas todas las noches, empareja productos con búsqueda vectorial y resuelve la división con un solver de restricciones. Delivery-note finderBuscador de remitosautomation · ocr

Finds scanned delivery notes by number for an accounting team that cross-checks them when entering invoices: ~45,000 a year, saved under file names unrelated to their numbers. OCR runs locally because the documents are confidential. It re-reads the number area digits-only and votes between readings, flags doubtful reads instead of guessing, and turns a list of numbers into an Excel report. Used by 3 people, it saves hours on every cross-check.

Encuentra remitos escaneados por número para un equipo contable que los cruza al cargar facturas: unos 45.000 por año, guardados con nombres que no tienen nada que ver con su número. El OCR corre local porque los documentos son confidenciales. Relee la zona del número solo con dígitos y vota entre lecturas, marca las lecturas dudosas en vez de adivinar y convierte una lista de números en un reporte de Excel. Lo usan 3 personas y ahorra horas en cada cruce.

Job digestautomation · llm

Every weekday at 8 a.m. a GitHub Actions job pulls fresh postings from LinkedIn, Indeed, GetOnBoard and company career pages, filters them and scores each one from 0 to 10 against a person's profile with Claude Haiku. For the best matches it writes a one-page CV tailored to the posting, using only facts from the profile, and emails a digest. Personal data never touches the public repo: it travels as GitHub secrets. It has screened about 870 postings for 2 people so far.

Cada día hábil a las 8 de la mañana, un job de GitHub Actions trae ofertas nuevas de LinkedIn, Indeed, GetOnBoard y portales de empresas, las filtra y puntúa cada una del 0 al 10 contra el perfil de una persona con Claude Haiku. Para las que mejor encajan arma un CV de una página adaptado a la oferta, solo con datos del perfil, y manda un resumen por mail. Los datos personales nunca tocan el repo público: viajan como secrets de GitHub. Ya filtró unas 870 ofertas para 2 personas.

Python · GitHub Actions · Claude (Haiku, Sonnet) · JobSpy · Jinja2 · headless Chrome
